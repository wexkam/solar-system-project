# Информационное агентство "Ulan-Ude news"

Система для агрегации и распространения новостной информации с использованием паттерна Observer.

## Описание

Информационное агентство "Ulan-Ude news" аккумулирует различную информацию и публикует её для подписчиков. Система поддерживает три типа сообщений:

1. **Тип 1** - Информация о погоде
2. **Тип 2** - Курс валют  
3. **Тип 3** - Новости города

## Особенности реализации

### ✅ Паттерн Observer
- **Subject (NewsAgency)** - управляет списком наблюдателей и уведомляет их о новых сообщениях
- **Observer (InformPolis, ArigUs, CustomObserver)** - получают уведомления о новых сообщениях

### ✅ Добавление новых наблюдателей без изменения кода
- Создайте класс, наследующий от `Observer`
- Реализуйте метод `update()`
- Подпишите на агентство через `agency.attach(observer)`

### ✅ Удаление наблюдателей
- Используйте метод `agency.detach(observer)`

### ✅ Чтение данных из файла с задержкой 5 секунд
- Автоматическое чтение новых строк из файла
- Настраиваемая задержка (по умолчанию 5 секунд)
- Обработка ошибок и отсутствующих файлов

### ✅ Вывод информации в консоль
- Каждый наблюдатель выводит информацию о полученных сообщениях
- Формат: "Наблюдатель получил информацию: <Текст>, <Дата>, <Тип>"

## Формат данных

Сообщения в файле должны быть в формате:
```
<содержимое>; <дата в формате YYYY-mm-dd>; <тип сообщения>
```

Пример:
```
-15 1 20; 2020-11-14; 1
dollar 74; 2020-11-14; 2
Курс доллара опять растёт он стал 74; 2020-11-14; 3
```

```bash

```

### 💻 Программный интерфейс:
```python
from news_agency import NewsAgency
from observers import InformPolis, ArigUs
from message import Message

# Создание агентства и наблюдателей
agency = NewsAgency()
inform_polis = InformPolis()
arig_us = ArigUs()

# Подписка
agency.attach(inform_polis)
agency.attach(arig_us)

# Отправка сообщения
message = Message("Температура -5", "2020-12-01", 1)
agency.add_message(message)

# Чтение из файла
agency.start_reading_from_file('news_data.txt', delay=5)
```

## Классы наблюдателей

### InformPolis (Газета "Информ полис")
- Получает все типы сообщений
- Ведет статистику по типам сообщений

### ArigUs (Телеканал "Ариг Ус")  
- Заинтересован только в погоде и новостях города
- Игнорирует сообщения о валютах
- Настраиваемые типы интересов

### CustomObserver (Пользовательский наблюдатель)
- Демонстрирует возможность добавления новых наблюдателей
- Настраиваемое имя и фильтры типов сообщений

## Требования

- Python 3.6+
- Стандартная библиотека Python (threading, time, abc, enum)

## Архитектурные преимущества

1. **Слабая связанность** - наблюдатели не знают друг о друге
2. **Расширяемость** - легко добавлять новых наблюдателей
3. **Гибкость** - каждый наблюдатель может по-своему обрабатывать сообщения
4. **Многопоточность** - чтение файла происходит в отдельном потоке
5. **Обработка ошибок** - система устойчива к ошибкам чтения файла
