# 📰 Информационное агентство "Ulan-Ude news"

## Описание проекта

Реализация паттерна **Observer (Наблюдатель)** для информационного агентства "Ulan-Ude news", которое собирает и распространяет различную информацию среди подписчиков.

## 🎯 Функциональность

### Типы сообщений:
- **Тип 1** - Информация о погоде
- **Тип 2** - Курс валют  
- **Тип 3** - Новости города

### Наблюдатели (Подписчики):
- **Информ полис** - Газета
- **Ариг Ус** - Телеканал

## 🏗️ Структура проекта

```
/workspace/
├── index.html          # Веб-интерфейс для тестирования
├── news_agency.js      # Реализация паттерна Observer
├── news_data.txt       # Файл с тестовыми данными
└── README.md          # Документация проекта
```

## 📐 Архитектура (Паттерн Observer)

### Классы:

#### 1. `Observer` (Абстрактный класс)
Базовый класс для всех наблюдателей
- `update(message, date, type)` - метод для получения обновлений

#### 2. `InformPolis` и `ArigUs` (Конкретные наблюдатели)
Реализуют интерфейс Observer
- Получают и выводят уведомления в консоль

#### 3. `NewsAgency` (Субъект)
Управляет подписчиками и рассылкой новостей
- `addObserver(observer)` - добавить наблюдателя
- `removeObserver(observer)` - удалить наблюдателя
- `notifyObservers(message, date, type)` - оповестить всех подписчиков
- `readFromFile(fileContent)` - чтение данных из файла с задержкой 5 секунд

## 🚀 Как использовать

### Вариант 1: Открыть в браузере

1. Откройте файл `index.html` в браузере
2. Подпишите наблюдателей, нажав на кнопки подписки
3. Нажмите "Начать чтение из файла"
4. Наблюдайте за обработкой сообщений с задержкой в 5 секунд
5. Откройте консоль браузера (F12) для просмотра детальных логов

### Вариант 2: Локальный сервер

```bash
# Python 3
python -m http.server 8000

# Затем откройте в браузере:
# http://localhost:8000
```

## 📝 Формат данных в файле

Каждая строка имеет формат: `сообщение; дата; тип`

**Примеры:**

```
-15 1 20; 2020-11-14; 1
dollar 74; 2020-11-14; 2
euro 90; 2020-11-14; 2
Курс доллара опять растёт он стал 74;2020-11-14;3
Сегодня солнечно, температура +5;2020-11-15;1
```

### Пояснение к примерам:

- `-15 1 20; 2020-11-14; 1` 
  - Температура -15, вид осадков 1, скорость ветра 20
  - Дата: 2020-11-14
  - Тип: погода (1)

- `dollar 74; 2020-11-14; 2`
  - Курс доллара: 74
  - Дата: 2020-11-14
  - Тип: курс валют (2)

- `Курс доллара опять растёт он стал 74;2020-11-14;3`
  - Новость: "Курс доллара опять растёт он стал 74"
  - Дата: 2020-11-14
  - Тип: новость города (3)

## ✅ Соответствие требованиям

- ✅ Позволяет добавлять новых наблюдателей без изменения кода
- ✅ Позволяет удалять наблюдателей
- ✅ Считывание данных производится из текстового файла с задержкой в 5 секунд

## 🎨 Особенности реализации

1. **Гибкая архитектура** - легко добавить новых наблюдателей, расширив класс Observer
2. **Визуальный интерфейс** - современный веб-интерфейс с отображением статуса подписок
3. **Асинхронная обработка** - использование async/await для обработки с задержками
4. **Обработка ошибок** - валидация формата данных и обработка исключений
5. **Двойной вывод** - в консоль браузера и на веб-страницу

## 🔧 Расширение функционала

Чтобы добавить нового наблюдателя:

```javascript
class NewObserver extends Observer {
    constructor() {
        super();
        this.name = "Название наблюдателя";
    }

    update(message, date, type) {
        console.log(`${this.name} получил: ${message}`);
        // Ваша логика обработки
    }
}

// Использование
const newObserver = new NewObserver();
agency.addObserver(newObserver);
```
