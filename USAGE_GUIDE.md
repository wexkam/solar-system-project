# 📖 Руководство по использованию

## 🚀 Быстрый старт

### Вариант 1: Веб-интерфейс (Рекомендуется)

1. **Запустите локальный сервер:**

```bash
# С помощью Python 3
python3 -m http.server 8000

# Или с помощью Python 2
python -m SimpleHTTPServer 8000

# Или с помощью Node.js (если установлен http-server)
npx http-server -p 8000
```

2. **Откройте браузер:**
   - Перейдите по адресу: `http://localhost:8000`
   - Откройте `index.html`

3. **Используйте интерфейс:**
   - Нажмите кнопки "Подписать" для добавления наблюдателей
   - Нажмите "Начать чтение из файла" для запуска рассылки
   - Откройте консоль браузера (F12) для детального просмотра

## 📋 Что делает программа

### Процесс работы:

1. **Инициализация**
   - Создается информационное агентство "Ulan-Ude news"
   - Создаются наблюдатели: "Информ полис" (газета) и "Ариг Ус" (телеканал)

2. **Подписка**
   - Наблюдатели подписываются на получение новостей
   - Можно добавлять и удалять подписчиков динамически

3. **Чтение данных**
   - Программа читает файл `news_data.txt`
   - Обрабатывает каждое сообщение
   - Делает паузу 5 секунд между сообщениями

4. **Рассылка**
   - Каждое сообщение отправляется всем подписчикам
   - Подписчики выводят полученную информацию в консоль

## 🎯 Примеры использования

### Пример 1: Базовая работа

```javascript
// Создание агентства
const agency = new NewsAgency();

// Создание наблюдателей
const newspaper = new InformPolis();
const tvChannel = new ArigUs();

// Подписка
agency.addObserver(newspaper);
agency.addObserver(tvChannel);

// Отправка новости
agency.notifyObservers("Температура -15", "2020-11-14", 1);
```

**Вывод:**
```
--- Ulan-Ude news рассылает информацию ---
Информ полис получил информацию: Температура -15, 2020-11-14, Погода
Ариг Ус получил информацию: Температура -15, 2020-11-14, Погода
```

### Пример 2: Удаление наблюдателя

```javascript
// Отписка газеты
agency.removeObserver(newspaper);

// Теперь только телеканал получит сообщение
agency.notifyObservers("Курс доллара: 74", "2020-11-14", 2);
```

**Вывод:**
```
Наблюдатель Информ полис отписан от Ulan-Ude news

--- Ulan-Ude news рассылает информацию ---
Ариг Ус получил информацию: Курс доллара: 74, 2020-11-14, Курс валют
```

### Пример 3: Добавление нового наблюдателя

Создайте новый класс наблюдателя:

```javascript
class RadioStation extends Observer {
    constructor() {
        super();
        this.name = "Радио Улан-Удэ";
    }

    update(message, date, type) {
        console.log(`🔊 ${this.name} транслирует: ${message}`);
    }
}

// Использование
const radio = new RadioStation();
agency.addObserver(radio);
```

## 📊 Формат данных

### Структура файла `news_data.txt`:

```
сообщение; дата; тип
```

- **сообщение** - текст новости (может содержать любые символы)
- **дата** - формат YYYY-MM-DD (например, 2020-11-14)
- **тип** - целое число (1, 2 или 3)

### Типы сообщений:

| Тип | Описание | Пример |
|-----|----------|--------|
| 1 | Погода | `-15 1 20; 2020-11-14; 1` |
| 2 | Курс валют | `dollar 74; 2020-11-14; 2` |
| 3 | Новости города | `Открытие музея; 2020-11-14; 3` |

## 🐛 Решение проблем

### Проблема: Файл не загружается в браузере

**Решение:** Убедитесь, что вы запустили локальный веб-сервер. Браузеры блокируют прямой доступ к локальным файлам из соображений безопасности.

### Проблема: Нет вывода в консоли

**Решение:** 
1. Откройте консоль браузера (F12)
2. Проверьте вкладку "Console"
3. Убедитесь, что наблюдатели подписаны перед запуском

### Проблема: Ошибка формата данных

**Решение:** Проверьте формат в файле `news_data.txt`:
- Каждая строка должна содержать три части, разделенные точкой с запятой
- Тип должен быть целым числом
- Не должно быть лишних пробелов в начале/конце строк

## 📈 Расширенные возможности

### Фильтрация по типу сообщений:

```javascript
class SelectiveObserver extends Observer {
    constructor(name, interestedTypes) {
        super();
        this.name = name;
        this.interestedTypes = interestedTypes;
    }

    update(message, date, type) {
        if (this.interestedTypes.includes(type)) {
            console.log(`${this.name} получил: ${message}`);
        }
    }
}

// Наблюдатель, интересующийся только погодой и валютой
const weatherFinance = new SelectiveObserver("WeatherFinance", [1, 2]);
agency.addObserver(weatherFinance);
```

### Логирование в файл (Node.js):

```javascript
const fs = require('fs');

class FileLogger extends Observer {
    constructor() {
        super();
        this.name = "FileLogger";
        this.logFile = 'news_log.txt';
    }

    update(message, date, type) {
        const logEntry = `[${date}] Тип ${type}: ${message}\n`;
        fs.appendFileSync(this.logFile, logEntry);
    }
}
```

## 🎓 Дополнительные ресурсы

### Паттерн Observer:
- Позволяет объектам оповещать другие объекты об изменении состояния
- Реализует принцип "один-ко-многим"
- Слабая связанность между объектами

### Преимущества реализации:
1. Легко добавлять новых наблюдателей
2. Не нужно изменять код агентства
3. Динамическая подписка/отписка
4. Масштабируемость
